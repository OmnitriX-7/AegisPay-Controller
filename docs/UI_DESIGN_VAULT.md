## 📐 How We Apply These in Projects
1. **Color Systems**: Obsidian/Slate dark modes with tailored HSL tokens (Cyan `#06b6d4`, Emerald `#10b981`, Razorpay Blue `#528ff0`, Amber `#f59e0b`).
2. **Typography**: Modern paired fonts (`Plus Jakarta Sans` / `Inter` for headings/body + `JetBrains Mono` for code/financials).
3. **Interactive Data Surfaces**: Clickable table rows opening formal proof drawers/modals, live SVG/Canvas trajectory charts with hover tooltips, and real-time step visualizers.
